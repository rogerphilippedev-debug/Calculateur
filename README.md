Calculateur de Rouleaux de Papier Peint

Une application web simple et légère conçue pour calculer rapidement le nombre exact de rouleaux de papier peint nécessaires pour une pièce, en tenant compte des dimensions, des marges de coupe et des raccords de motifs.

Fonctionnalités
 Calcul précis : Basé sur le périmètre de la pièce et la hauteur sous plafond.
  Gestion des raccords : Intègre la prise en compte des raccords de motifs en centimètres.
  Marge de sécurité : Ajoute automatiquement 10 cm de marge de coupe par lé pour éviter les manques.
  100% Responsive : Optimisé pour une utilisation fluide sur smartphone directement via ce lien :
   https://rogerphilippedev-debug.github.io/Calculateur/

Utilisation
L'application est contenue dans un fichier unique `index.html` et ne nécessite aucune installation ni serveur complexe. Elle peut être ouverte directement dans n'importe quel navigateur web moderne.

Hébergement
Ce projet est configuré pour être hébergé gratuitement et simplement via GitHub Pages.
